Generally covered

Static commercial and non-commercial designs, including logos, print, packaging, merchandise, images, slides, and rendered video.

Needs another license

Webfonts, apps, games, e-books, software, devices, servers, SaaS, editable templates, personalization, and similar embedding uses.

Not permitted

Sharing or modifying the font, making reusable alphabet products, or using it or its rendered visual elements to train AI or machine-learning models.

What you can make

Commercial or non-commercial, once the type is fixed.

You may create finished materials in which the lettering is fixed artwork and the font software is not distributed. These examples are illustrative, not exhaustive:

  • Logos, wordmarks, brand graphics, and advertising
  • Books in print, posters, signs, brochures, and other printed matter
  • Packaging, labels, clothing, merchandise, and physical products
  • Flat images and graphics exported as formats such as JPG, PNG, or outlined SVG
  • Presentation slides and rendered audiovisual or motion-graphics work
The simple test: viewers can see the lettering, but they cannot access the font, extract it, edit text with it, or use it to compose new text.

One person, one license

The included license is for one natural person.

The licensed user may install and use the font on computers under that person’s control. If a colleague, employee, contractor, agency, or client needs to install or use the font, that person should obtain an authorized copy and accept their own license.

Do not place the working font on a shared server, shared network folder, cloud-font library, or digital asset system. A private backup that other people cannot access is fine.

Larger organizations, centrally managed installations, or multi-user workflows may need a separate agreement.

Find the right license

PDFs: check how the font is included

“It’s a PDF” is not enough to determine the license.

Outlined or rasterized artwork

A commercial PDF can be a permitted finished material when its lettering has been converted to outlines or pixels and the PDF contains no font software.

Embedded font software

The included license has a narrow exception for a non-commercial PDF when the embedded font cannot be extracted, the text cannot be edited through the embedded font, and readers cannot use it to compose new text.

Sold or commercial electronic publications

An e-book, sold publication, or commercial PDF containing embedded font software requires a separate written license.

Important restrictions

Please keep the font itself intact and private.

  • Do not give, sell, upload, sublicense, or otherwise share the font software.
  • Do not modify, rename, convert, adapt, subset, reverse-engineer, or create a derivative font.
  • Do not sell or distribute reusable letters, numbers, glyph sets, alphabet kits, or similar products that let recipients compose new text or designs.
  • Do not include the font in open-source or publicly available software where the font could be redistributed.
  • Do not use the font software, its tables or outlines, its spacing or kerning data, or its rendered visual elements to develop, train, or fine-tune an AI or machine-learning model.

Ordinary use of AI-powered software is not automatically prohibited. The restriction applies when the font or material derived from it is supplied as training or development material for a model. See the EULA for the exact rule.

Install the font

Extract the ZIP file before installing.

Windows

Extract the ZIP file, select the font files, right-click, and choose Install. Depending on your version of Windows, you can also open a font file and select Install.

macOS

Extract the ZIP file, double-click a font file, and choose Install Font in Font Book.
